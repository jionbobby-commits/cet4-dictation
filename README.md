# CET-4 Dictation

**英语四级听写与学习辅助工具**

## 项目简介

我在备考英语四级的时候，试过不少单词听写工具，但总觉得要么广告太多，要么计划不符合自己的节奏，要么数据不能完全自己掌控。所以就想自己做一个简单、干净、完全本地的听写网站。

这个项目的目标很简单：帮 CET-4 学习者按天进行单词听写练习，记录学习进度，不用注册登录，打开网页就能用。所有数据都存在浏览器本地，不会上传到任何服务器。

## 在线体验

直接访问：
https://jionbobby-commits.github.io/cet4-dictation/

推荐用 Chrome 或 Edge 浏览器，语音朗读效果最好。

## 主要功能

### 听写练习
- **语音朗读**：支持美式英语发音，在线 TTS 优先，系统语音备用
- **手写输入**：Canvas 手写板，支持鼠标和触屏，带笔粗调节和清空
- **键盘输入**：备用答案输入方式
- **自动批改**：忽略大小写和首尾空格，即时反馈对错
- **三种听写模式**：听英文写中文、听中文写英文、看英文选中文

### 学习计划
- **按日期分配任务**：从 Excel 导入的 262 天完整计划，严格按真实日期对应单词
- **任务状态管理**：每个任务可以手动标记为已完成、未完成、补做或未标记
- **日期自动判断**：根据今天的日期自动标记过期任务为"补做"
- **日期范围筛选**：可以调整计划查看的起始和结束日期

### 学习统计
- **今日学习进度**：当天计划单词数、已完成数
- **累计学习单词**：根据已完成任务和实际听写记录统计
- **听写正确率**：基于真实作答记录计算
- **连续学习天数**：记录连续学习的天数
- **错题本**：答错的单词自动收录，方便复习

### 界面设计
- **Google Material 3 风格**：鼠尾草绿配色系统，简洁清新
- **响应式布局**：手机和电脑都能正常使用
- **微交互动效**：卡片淡入、按钮按压反馈，流畅不突兀

## 技术实现

这是一个纯前端静态网站，不需要后端服务器，也不需要构建工具。

| 模块 | 技术 | 说明 |
|------|------|------|
| 页面结构 | 原生 HTML | 单页应用，所有功能在一个页面里 |
| 样式 | 原生 CSS | Material 3 设计风格，CSS 变量统一配色 |
| 交互逻辑 | 原生 JavaScript (ES6) | 无框架依赖，代码轻量 |
| 语音播放 | Web Speech API + 在线 TTS | 双方案备用，兼容性更好 |
| 手写板 | HTML Canvas | Pointer Events 实现，支持鼠标和触屏 |
| 本地存储 | IndexedDB | 学习记录、错题本、设置全部本地保存 |
| 手写识别 | Tesseract.js (CDN) | 浏览器端 OCR，识别手写英文 |

## 本地运行

这是一个纯静态 HTML 项目，运行很简单。

**方法一：直接打开**

直接双击 `index.html` 用浏览器打开即可。

> 注意：某些浏览器在 `file://` 协议下会限制语音功能，推荐用下面的本地服务器方式。

**方法二：本地服务器（推荐）**

如果你电脑上装了 Python：

```bash
cd cet4-dictation
python -m http.server 8080
```

然后浏览器访问：http://localhost:8080

## 已知限制

1. **语音兼容性**：Web Speech API 在 Safari 上支持较差，推荐使用 Chrome / Edge
2. **手写识别准确率**：Tesseract.js 浏览器端对手写英文的识别率有限，这是浏览器端 OCR 的天生限制
3. **数据隔离**：数据保存在浏览器本地，换浏览器或换设备看不到之前的数据
4. **词库说明**：内置词库是按我自己的学习计划整理的，对应 Excel 中的每日单词列表
